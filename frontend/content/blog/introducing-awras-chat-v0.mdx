Six months ago the annotation studio held 40,000 pairs and a single accent.
Today **awras-chat-v0** is trained on 1.2 million pairs contributed by 214
annotators across Algeria — and for the first time, a model answers a question
about a bus schedule in Oran the way someone from Oran would ask it.

This post covers what the model does well, where it fails, and how the
leaderboard quietly became our most important data-quality tool.

## What we shipped

A 7B instruction-tuned model, a transliteration normaliser that maps Arabizi to
Arabic script before tokenisation, and an evaluation set of 3,000 held-out
prompts written by native speakers rather than translated from English.

## Results

Human preference against two multilingual baselines, judged by 30 native
speakers on 500 prompts. Numbers are win rates.

| Model                        | Darija fluency | Task accuracy |
| ---------------------------- | -------------- | ------------- |
| Baseline A (multilingual 8B) | 31%            | 54%           |
| Baseline B (MSA-tuned 7B)    | 44%            | 58%           |
| **awras-chat-v0**            | **78%**        | **71%**       |

## Where it still breaks

Code-switching mid-sentence between Darija and French is handled; switching into
Tamazight is not. Long-form generation drifts toward MSA after roughly 200
tokens. And the model is confidently wrong about anything local and recent —
prices, schedules, administrative procedures.

Next up is v0.2 with Chaoui and Kabyle coverage, plus a speech front-end built
on the 40-hour corpus. If you want to help, the queue is open.
